# Security

## Leaked API keys

If you find an API key, token or password in this repository, in an issue or in a pull request, please **do not repeat it publicly**. Report it privately through GitHub's *Report a vulnerability* button on the *Security* tab of this repository.

If your own key was exposed, request a new one from the provider (for ENTSO-E: the Transparency Platform helpdesk) and delete the old one.

## Other vulnerabilities

Please use the same private reporting channel. You will receive an answer as soon as possible.
